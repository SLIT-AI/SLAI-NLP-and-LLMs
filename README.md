# Natural Language Processing and Large Language Models

Course website for the Shenzhen Loop Area Institute, Term 1 of Academic Year 2026–2027.

## Local preview

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173`.

## GitHub Pages

The workflow in `.github/workflows/pages.yml` publishes the website whenever `main` is updated. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**.
